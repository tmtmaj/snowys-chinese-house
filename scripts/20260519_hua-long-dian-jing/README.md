# 画龙点睛 (huà lóng diǎn jīng)

> **한국어 의미**: 화룡점정 — 마지막 결정적인 한 획으로 전체를 완성시키다

## 성어 요약

- **글자 그대로**: 용을 그리고 나서 눈동자를 점찍다
- **비유적 의미**: 핵심적인 곳에 결정적인 한 마디(한 획)를 더해 전체를 살아있게 만들다
- **근의어**: 点石成金, 一语中的
- **주의**: 불필요한 것을 덧붙이는 건 画蛇添足!

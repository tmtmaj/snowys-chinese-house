## ③ 字义分析
### 【青 · qīng】
**中文**
```
「青」，本来的意思是绿色，也有年轻、未成熟的意思。
```
**拼音**
```
「qīng」, běnlái de yìsi shì lǜsè, yě yǒu niánqīng、wèi chéngshú de yìsi.
```
**영어**
```
「青」 originally means green, but also carries the meaning of youthful or unripe.
```

**中文**
```
「青春」——人生中最年轻的时光，充满活力和希望。
```
**拼音**
```
「qīngchūn」—— rénshēng zhōng zuì niánqīng de shíguāng, chōngmǎn huólì hé xīwàng.
```
**영어**
```
「青春」 — the youngest, most vibrant season of life, full of energy and hope.
```

**中文**
```
「青年」，年轻人的意思。
```
**拼音**
```
「qīngnián」, niánqīngrén de yìsi.
```
**영어**
```
「青年」 means a young person.
```

**中文**
```
「青涩」，形容人还不成熟，有点害羞、紧张的样子——就像没有熟透的青梅，有点酸。
```
**拼音**
```
「qīngsè」, xíngróng rén hái bù chéngshú, yǒudiǎn hàixiū、jǐnzhāng de yàngzi —— jiù xiàng méi yǒu shú tòu de qīngméi, yǒudiǎn suān.
```
**영어**
```
「青涩」 describes someone still immature, a little shy and nervous — like an unripe plum that's still a bit sour.
```

### 【梅 · méi】
**中文**
```
「梅」，是梅子，梅树结的果实。
```
**拼音**
```
「méi」, shì méizi, méishù jié de guǒshí.
```
**영어**
```
「梅」 refers to the plum — the fruit of the plum tree.
```

**中文**
```
「梅花」，冬天开放的花，在中国文化里象征坚韧和高洁。
```
**拼音**
```
「méihuā」, dōngtiān kāifàng de huā, zài zhōngguó wénhuà lǐ xiàngzhēng jiānrèn hé gāojié.
```
**영어**
```
「梅花」, the plum blossom, blooms in winter and symbolizes resilience and purity in Chinese culture.
```

**中文**
```
「梅雨」，每年夏初多雨的季节——因为那时候梅子正好成熟，所以叫梅雨。
```
**拼音**
```
「méiyǔ」, měi nián xià chū duō yǔ de jìjié —— yīnwèi nà shíhou méizi zhènghǎo chéngshú, suǒyǐ jiào méiyǔ.
```
**영어**
```
「梅雨」 is the rainy season in early summer — called plum rain because that's when plums ripen.
```

**中文**
```
在这个成语里，「青梅」是还没有熟透的梅子——象征着孩子天真无邪的童年时光。
```
**拼音**
```
zài zhège chéngyǔ lǐ, 「qīngméi」 shì hái méi yǒu shú tòu de méizi —— xiàngzhēng zhe háizi tiānzhēn wúxié de tóngnián shíguāng.
```
**영어**
```
In this idiom, 「青梅」 — green unripe plums — symbolize the innocent, carefree childhood of a little girl.
```

### 【竹 · zhú】
**中文**
```
「竹」，是竹子，中国最常见的植物之一。
```
**拼音**
```
「zhú」, shì zhúzi, zhōngguó zuì chángjiàn de zhíwù zhī yī.
```
**영어**
```
「竹」 is bamboo — one of the most common plants in China.
```

**中文**
```
「竹林」，竹子组成的树林，安静又清幽。
```
**拼音**
```
「zhúlín」, zhúzi zǔchéng de shùlín, ānjìng yòu qīngyōu.
```
**영어**
```
「竹林」 is a bamboo grove — quiet and serene.
```

**中文**
```
「竹马」，就是用竹竿做成的玩具马——孩子把竹竿夹在腿之间，像骑马一样跑来跑去。
```
**拼音**
```
「zhúmǎ」, jiù shì yòng zhúgān zuòchéng de wánjù mǎ —— háizi bǎ zhúgān jiā zài tuǐ zhī jiān, xiàng qí mǎ yīyàng pǎo lái pǎo qù.
```
**영어**
```
「竹马」 is a toy horse made from a bamboo pole — children would tuck it between their legs and run around as if riding a real horse.
```

### 【马 · mǎ】
**中文**
```
「马」，就是马，古代最重要的交通工具。
```
**拼音**
```
「mǎ」, jiù shì mǎ, gǔdài zuì zhòngyào de jiāotōng gōngjù.
```
**영어**
```
「马」 is a horse — the most important means of transportation in ancient times.
```

**中文**
```
「骑马」，就是骑着马走。
```
**拼音**
```
「qí mǎ」, jiù shì qí zhe mǎ zǒu.
```
**영어**
```
「骑马」 means to ride a horse.
```

**中文**
```
「马上」，字面意思是在马背上，引申为立刻——因为骑着马随时可以出发。
```
**拼音**
```
「mǎshàng」, zìmiàn yìsi shì zài mǎ bèi shàng, yǐnshēn wèi lìkè —— yīnwèi qí zhe mǎ suíshí kěyǐ chūfā.
```
**영어**
```
「马上」 literally means 'on horseback,' extended to mean 'immediately' — because a rider on horseback can set off at any moment.
```

## ④ 成语整体含义
**中文**
```
我们先来看「青梅」和「竹马」各自的意思。
```
**拼音**
```
wǒmen xiān lái kàn 「qīngméi」 hé 「zhúmǎ」 gège de yìsi.
```
**영어**
```
Let's look at what 「青梅」 and 「竹马」 each mean on their own.
```

**中文**
```
「青梅」，是女孩子玩的青色梅子；「竹马」，是男孩子骑的竹竿马。
```
**拼音**
```
「qīngméi」, shì nǚháizi wán de qīngsè méizi; 「zhúmǎ」, shì nánháizi qí de zhúgān mǎ.
```
**영어**
```
「青梅」 is the green plum a little girl plays with; 「竹马」 is the bamboo horse a little boy rides.
```

**中文**
```
合在一起，「青梅竹马」字面上描述的是：一个小女孩摘着青梅，一个小男孩骑着竹马，在一起无忧无虑地玩耍。
```
**拼音**
```
hé zài yīqǐ, 「qīng méi zhú mǎ」 zìmiàn shàng miáoshù de shì: yī gè xiǎo nǚhái zhāi zhe qīngméi, yī gè xiǎo nánhái qí zhe zhúmǎ, zài yīqǐ wúyōu wúlǜ de wánshuǎ.
```
**영어**
```
Together, 「青梅竹马」 literally pictures a little girl picking green plums while a little boy rides his bamboo horse — two children playing together without a care in the world.
```

**中文**
```
引申出来，「青梅竹马」形容从小一起长大的男女，两人之间有一种特别深厚、纯粹的感情。
```
**拼音**
```
yǐnshēn chūlái, 「qīng méi zhú mǎ」 xíngróng cóng xiǎo yīqǐ zhǎngdà de nánnǚ, liǎng rén zhī jiān yǒu yī zhǒng tèbié shēnhòu、chúncuì de gǎnqíng.
```
**영어**
```
Figuratively, 「青梅竹马」 describes a boy and girl who grew up together, sharing a bond that is especially deep and pure.
```

**中文**
```
这个成语通常带着温暖、怀念的感情色彩。
```
**拼音**
```
zhège chéngyǔ tōngcháng dài zhe wēnnuǎn、huáiniàn de gǎnqíng sècǎi.
```
**영어**
```
This idiom usually carries a warm, nostalgic emotional tone.
```

**中文**
```
和「青梅竹马」意思很近的，还有「两小无猜」——这其实来自同一首诗，意思是两个孩子之间天真无邪、没有任何猜忌。
```
**拼音**
```
hé 「qīng méi zhú mǎ」 yìsi hěn jìn de, hái yǒu 「liǎng xiǎo wú cāi」 —— zhè qíshí lái zì tóngyī shǒu shī, yìsi shì liǎng gè háizi zhī jiān tiānzhēn wúxié、méi yǒu rènhé cāijì.
```
**영어**
```
A closely related phrase is 「两小无猜」— which comes from the same poem. It means two children who are innocent and free of any suspicion toward each other.
```

## ⑤ 成语来源
> 📜 **唐·李白 · 《长干行》**

**中文**
```
这个成语出自唐代大诗人李白的《长干行》。
```
**拼音**
```
zhège chéngyǔ chūzì táng dài dà shīrén lǐ bái de 《cháng gān xíng》.
```
**영어**
```
This idiom comes from 《长干行》 by Li Bai, one of the greatest poets of the Tang Dynasty.
```

**中文**
```
《长干行》是一首叙事诗，用一位女子的口吻，讲述她和丈夫从小相识、相爱的故事。
```
**拼音**
```
《cháng gān xíng》 shì yī shǒu xùshì shī, yòng yī wèi nǚzǐ de kǒuwěn, jiǎngshù tā hé zhàngfu cóng xiǎo xiāngshí、xiāng'ài de gùshi.
```
**영어**
```
《长干行》 is a narrative poem written in the voice of a woman, telling the story of how she and her husband knew each other and fell in love since childhood.
```

**中文**
```
「长干」是古代金陵的一个地名，也就是今天南京的一处街区。
```
**拼音**
```
「cháng gān」 shì gǔdài jīnlíng de yī gè dìmíng, yě jiù shì jīntiān nán jīng de yī chù jiēqū.
```
**영어**
```
「长干」 is the name of a neighborhood in ancient Jinling — what is today the city of Nanjing.
```

**中文**
```
诗里有这两句：「郎骑竹马来，绕床弄青梅。」
```
**拼音**
```
shī lǐ yǒu zhè liǎng jù: 「láng qí zhúmǎ lái, rào chuáng nòng qīngméi.」
```
**영어**
```
The poem contains these lines: 「The boy comes riding his bamboo horse, circling the bed playing with green plums.」
```

**中文**
```
还有：「同居长干里，两小无嫌猜。」
```
**拼音**
```
hái yǒu: 「tóng jū cháng gān lǐ, liǎng xiǎo wú xián cāi.」
```
**영어**
```
And: 「Living together in Chang Gan Lane, two small children with no suspicion between them.」
```

**中文**
```
这四句诗描述的是：一个小男孩骑着竹竿做的「马」跑来，绕着女孩的床玩耍，女孩在摘青梅——两个孩子住在同一条街，天天在一起，纯真无邪。
```
**拼音**
```
zhè sì jù shī miáoshù de shì: yī gè xiǎo nánhái qí zhe zhúgān zuò de 「mǎ」 pǎo lái, rào zhe nǚhái de chuáng wánshuǎ, nǚhái zài zhāi qīngméi —— liǎng gè háizi zhù zài tóngyī tiáo jiē, tiāntiān zài yīqǐ, chúnzhēn wúxié.
```
**영어**
```
These lines picture a little boy galloping over on his bamboo horse, circling the girl's bed while she plays with green plums — two children on the same lane, together every day, innocent and pure.
```

**中文**
```
后来，人们就用「青梅竹马」来形容从小一起长大、感情深厚的男女。
```
**拼音**
```
hòulái, rénmen jiù yòng 「qīng méi zhú mǎ」 lái xíngróng cóng xiǎo yīqǐ zhǎngdà、gǎnqíng shēnhòu de nánnǚ.
```
**영어**
```
Over time, people began using 「青梅竹马」 to describe a boy and girl who grew up together with a deep, lasting bond.
```

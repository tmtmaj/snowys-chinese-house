## ③ 字义分析
### 【盛 · shèng】
**中文**
```
盛，有强烈、旺盛的意思。我们说花开得很旺，叫盛开；夏天最热的时候，叫盛夏。
```
**拼音**
```
shèng, yǒu qiángliè, wàngshèng de yìsi. Wǒmen shuō huā kāi de hěn wàng, jiào shèngkāi; xiàtiān zuì rè de shíhòu, jiào shèngxià.
```
**영어**
```
Shèng means intense or flourishing. When flowers bloom fully, we say 盛开; the peak of summer is 盛夏.
```

**中文**
```
在盛气凌人里，盛形容的是气势——一种骄横、强烈的气焰，大到压迫别人的程度。
```
**拼音**
```
zài shèng qì líng rén lǐ, shèng xíngróng de shì qìshì — yī zhǒng jiāohèng, qiángliè de qìyàn, dà dào yāpò biérén de chéngdù.
```
**영어**
```
In 盛气凌人, 盛 describes the manner — an intense, arrogant air so overwhelming it oppresses others.
```

### 【气 · qì】
**中文**
```
气，在这里指的是气势、气焰，不是呼吸的气。
```
**拼音**
```
qì, zài zhèlǐ zhǐ de shì qìshì, qìyàn, bù shì hūxī de qì.
```
**영어**
```
Here, 气 means manner or aura — not the air we breathe, but the energy someone projects.
```

**中文**
```
我们说一个人傲气十足，或者说他气势汹汹地走进来——都是用这个气字来形容态度和气势。
```
**拼音**
```
wǒmen shuō yī gè rén àoqì shízú, huòzhě shuō tā qìshì xiōngxiōng de zǒu jìnlái — dōu shì yòng zhège qì zì lái xíngróng tàidù hé qìshì.
```
**영어**
```
We say someone is full of arrogance (傲气十足), or they storm in with an aggressive air (气势汹汹) — both use 气 to describe attitude and presence.
```

**中文**
```
盛气，合在一起，就是骄横强烈的气焰。
```
**拼音**
```
shèng qì, hé zài yīqǐ, jiùshì jiāohèng qiángliè de qìyàn.
```
**영어**
```
Together, 盛气 means an intense, arrogant, domineering air.
```

### 【凌 · líng】
**中文**
```
凌，是欺压、凌驾的意思。凌驾于别人之上，就是把自己放在比别人更高的位置，俯视别人。
```
**拼音**
```
líng, shì qīyā, língjià de yìsi. Língjià yú biérén zhī shàng, jiùshì bǎ zìjǐ fàng zài bǐ biérén gèng gāo de wèizhì, fǔshì biérén.
```
**영어**
```
Líng means to overpower or place oneself above others. 凌驾于别人之上 means to position yourself above others and look down on them.
```

**中文**
```
欺凌、凌辱——这两个词都有用强势压制别人的意味。
```
**拼音**
```
qīlíng, língrǔ — zhè liǎng gè cí dōu yǒu yòng qiángshì yāzhì biérén de yìwèi.
```
**영어**
```
欺凌 (bully) and 凌辱 (humiliate) both carry the sense of using force or power to suppress others.
```

### 【人 · rén】
**中文**
```
人，就是他人、别人。盛气凌人，就是用骄横的气势去压凌别人。
```
**拼音**
```
rén, jiùshì tārén, biérén. Shèng qì líng rén, jiùshì yòng jiāohèng de qìshì qù yā líng biérén.
```
**영어**
```
人 simply means other people. 盛气凌人 — using an arrogant air to overpower and intimidate others.
```

## ④ 成语整体含义
**中文**
```
好，我们把四个字合起来：盛气凌人。
```
**拼音**
```
hǎo, wǒmen bǎ sì gè zì hé qǐlái: shèng qì líng rén.
```
**영어**
```
Now let's put all four characters together: 盛气凌人.
```

**中文**
```
盛气，是骄横强烈的气势；凌人，是压制、欺凌别人。合起来，就是：用骄横的气势压制别人，形容态度傲慢、目中无人。
```
**拼音**
```
shèng qì, shì jiāohèng qiángliè de qìshì; líng rén, shì yāzhì, qīlíng biérén. Hé qǐlái, jiùshì: yòng jiāohèng de qìshì yāzhì biérén, xíngróng tàidù àomàn, mùzhōng wúrén.
```
**영어**
```
盛气 is an intense, arrogant air; 凌人 is suppressing or bullying others. Together: using an overbearing manner to intimidate people — describing someone arrogant and dismissive of everyone around them.
```

**中文**
```
重要的一点：这是一个贬义词，专门用来批评那些傲慢、高高在上的人。
```
**拼音**
```
zhòngyào de yī diǎn: zhè shì yī gè biǎnyìcí, zhuānmén yòng lái pīpíng nàxiē àomàn, gāogāo zài shàng de rén.
```
**영어**
```
Important: this is a negative term, used specifically to criticize people who are arrogant and condescending.
```

**中文**
```
和盛气凌人意思相近的成语，有咄咄逼人——形容说话时气势逼人，让人难以应对；还有趾高气扬——形容骄傲自满、神气十足的样子。
```
**拼音**
```
hé shèng qì líng rén yìsi xiāngjìn de chéngyǔ, yǒu duōduō bī rén — xíngróng shuōhuà shí qìshì bī rén, ràng rén nányǐ yìngduì; hái yǒu zhǐ gāo qì yáng — xíngróng jiāoào zìmǎn, shénqì shízú de yàngzi.
```
**영어**
```
Similar idioms include 咄咄逼人 (overwhelmingly aggressive in speech, hard to deal with) and 趾高气扬 (strutting around full of pride and arrogance).
```

**中文**
```
反义词呢，是平易近人——形容态度谦和，容易接近，和盛气凌人完全相反。
```
**拼音**
```
fǎnyìcí ne, shì píngyì jìn rén — xíngróng tàidù qiānhé, róngyì jiējìn, hé shèng qì líng rén wánquán xiāngfǎn.
```
**영어**
```
The antonym is 平易近人 (approachable, humble, easy to get along with) — the complete opposite of 盛气凌人.
```

## ⑤ 成语来源
> 📜 **南宋·朱熹 · 《朱子全书·学五·教人》**

**中文**
```
这个成语最早见于南宋著名理学家朱熹的著作《朱子全书》。
```
**拼音**
```
zhège chéngyǔ zuìzǎo jiàn yú Nán Sòng zhùmíng lǐxuéjiā Zhū Xī de zhùzuò 《Zhūzǐ Quánshū》.
```
**영어**
```
This idiom first appears in 《朱子全书》, written by Zhu Xi, the great Neo-Confucian philosopher of the Southern Song dynasty.
```

**中文**
```
朱熹是南宋的大思想家，他把儒家学说系统化，对后世影响深远。《朱子全书》收录了他关于教育、修身、治学的大量思想。
```
**拼音**
```
zhū Xī shì Nán Sòng de dà sīxiǎngjiā, tā bǎ Rújiā xuéshuō xìtǒnghuà, duì hòushì yǐngxiǎng shēnyuǎn. 《Zhūzǐ Quánshū》 shōulù le tā guānyú jiàoyù, xiūshēn, zhìxué de dàliàng sīxiǎng.
```
**영어**
```
Zhu Xi was a great Southern Song thinker who systematized Confucian philosophy, with lasting influence on later generations. 《朱子全书》 collects his extensive ideas on education, self-cultivation, and scholarship.
```

**中文**
```
书中写道：不得盛气凌人，自取耻辱。
```
**拼音**
```
shū zhōng xiě dào: bù dé shèng qì líng rén, zì qǔ chǐrǔ.
```
**영어**
```
The text reads: 'One must not use an overbearing manner to intimidate others — that only brings shame upon oneself.'
```

**中文**
```
朱熹这句话是在告诫学生：做人不能骄傲自大、用强势的气势压制别人——这样做只会自取其辱。这句话体现了儒家一贯强调的谦逊之道。
```
**拼音**
```
zhū Xī zhè jù huà shì zài gàojiè xuésheng: zuòrén bù néng jiāoào zìdà, yòng qiángshì de qìshì yāzhì biérén — zhèyàng zuò zhǐ huì zìqǔ qí rǔ. Zhè jù huà tǐxiàn le Rújiā yīguàn qiángdiào de qiānxùn zhī dào.
```
**영어**
```
Zhu Xi was warning students: never be arrogant or use an overbearing manner to suppress others — doing so only brings shame on yourself. This reflects the Confucian emphasis on humility.
```

**中文**
```
此外，这个成语的背后，还有一个更古老的故事——战国时赵国的触龙劝说赵太后的典故。赵太后一开始盛气凌人，触龙却以智慧和耐心化解了她的傲慢，最终打动了她。这个故事记载在《战国策·赵策》里。出处参考：zdic.net（汉典）
```
**拼音**
```
cǐwài, zhège chéngyǔ de bèihòu, hái yǒu yī gè gèng gǔlǎo de gùshi — Zhànguó shí Zhào guó de Chù Lóng quànshuō Zhào Tàihòu de diǎngù. Zhào Tàihòu yīkāishǐ shèng qì líng rén, Chù Lóng què yǐ zhìhuì hé nàixīn huàjiě le tā de àomàn, zuìzhōng dǎdòng le tā. Zhège gùshi jìzài zài 《Zhànguócè · Zhào Cè》lǐ.
```
**영어**
```
Behind this idiom is also a much older story — from the Warring States period, the story of Chu Long persuading the Empress Dowager of Zhao. She started out completely overbearing, but Chu Long's wisdom and patience dissolved her arrogance and moved her. This story is recorded in 《Zhanguoce · Zhao Ce》. Source: zdic.net (Hàndian Dictionary)
```

## ⑦ 使用注意
**中文**
```
使用盛气凌人，要记住几点。
```
**拼音**
```
shǐyòng shèng qì líng rén, yào jìzhù jǐ diǎn.
```
**영어**
```
When using 盛气凌人, remember a few things.
```

**中文**
```
第一，它是贬义词，只用来批评人，不能用作称赞。如果你说一个人盛气凌人，那是在说他傲慢、让人不舒服。
```
**拼音**
```
dì yī, tā shì biǎnyìcí, zhǐ yòng lái pīpíng rén, bù néng yòng zuò chēngzàn. Rúguǒ nǐ shuō yī gè rén shèng qì líng rén, nà shì zài shuō tā àomàn, ràng rén bù shūfu.
```
**영어**
```
First, it's a negative term — only used to criticize, never to praise. If you say someone is 盛气凌人, you're saying they're arrogant and unpleasant to be around.
```

**中文**
```
第二，它通常用来形容人的态度和说话方式，不用来描述场面或事物。
```
**拼音**
```
dì èr, tā tōngcháng yòng lái xíngróng rén de tàidù hé shuōhuà fāngshì, bù yòng lái miáoshù chǎngmiàn huò shìwù.
```
**영어**
```
Second, it describes a person's attitude or speaking style — not scenes or things.
```

**中文**
```
第三，常见用法有：他盛气凌人地说道……；她的语气盛气凌人；也可以否定：他从不盛气凌人。
```
**拼音**
```
dì sān, chángjiàn yòngfǎ yǒu: tā shèng qì líng rén de shuōdào…; tā de yǔqì shèng qì líng rén; yě kěyǐ fǒudìng: tā cóng bù shèng qì líng rén.
```
**영어**
```
Third, common patterns: 他盛气凌人地说道… (he said in an overbearing manner…); 她的语气盛气凌人 (her tone was overbearing); or negated: 他从不盛气凌人 (he is never overbearing).
```

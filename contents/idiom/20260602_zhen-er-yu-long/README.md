## 성어 요약

- **글자 그대로**: 소리가 귀를 흔들어 거의 귀머거리가 될 정도
- **비유적 의미**: 소리가 극도로 크고 압도적임
- **어조**: 중립적 — 폭죽, 천둥, 콘서트 함성 등 다양한 맥락에 사용
- **주의**: 振聋发聩(zhèn lóng fā kuì)와 혼동 금지! 후자는 비유적 표현
- **근의어**: 震天动地, 响彻云霄
- **반의어**: 万籁无声, 万籁俱寂

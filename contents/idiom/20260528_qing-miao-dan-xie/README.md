# 轻描淡写 (qīng miáo dàn xiě)

> **한국어 의미**: 가볍게 묘사하고 담담하게 쓰다 — 중요한 일을 가볍게 넘기다, 대충 얼버무리다

## 성어 요약

- **글자 그대로**: 그림을 그리거나 글을 쓸 때 붓 터치가 가볍고 색이 옅다
- **비유적 의미**: 중요한 문제를 말할 때 대충 얼버무리고 제대로 다루지 않다
- **어조**: 주로 비판적 — 누군가가 심각한 일을 무성의하게 넘길 때 사용
- **근의어**: 蜻蜓点水, 一笔带过
- **반의어**: 浓墨重彩, 淋漓尽致

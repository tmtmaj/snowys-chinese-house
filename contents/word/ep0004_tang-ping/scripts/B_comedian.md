# EP0004 《躺平》 Script — Style B: 유머러스한 개그맨

### 🎬 Opening 📌 `00_title.png`

大家好！今天我们来学一个我最擅长的词——躺平！
躺是躺下，平是平平的，合起来就是舒舒服服躺着。
现在呢，躺平是指：不拼了，不卷了，怎么舒服怎么来。
说白了，就是我每个周末的状态。哈哈，我们开始吧！

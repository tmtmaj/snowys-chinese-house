# ep0012 · 恋爱脑 (liàn ài nǎo)

**의미**: (유행어) 연애만 시작하면 머릿속에 상대방밖에 안 남는 사람 (love brain) / 글자 그대로: 연애(恋爱) 뇌(脑) — 친구·일·자기 자신이 전부 뒤로 밀리는 상태. 놀리거나 걱정하는 뉘앙스로 쓰며, 반대말은 `事业脑`(일 우선).

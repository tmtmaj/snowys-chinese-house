# EP0006 《画饼》 Script — Style E: 스토리텔러/배우

### 🎬 Opening 📌 `00_title.png`

（轻声）很久以前，有个成语，叫"画饼充饥"——
饿的时候，画一个饼，看着它，仿佛就不那么饿了。
（停顿）千百年后，这个"饼"，走进了公司，走进了职场。
它变成了一句句好听的承诺，让人充满希望，却始终吃不到。
今天，我们讲一个关于"饼"的故事。

（停顿）一个能吃，一个只能看。故事，就从这里开始。

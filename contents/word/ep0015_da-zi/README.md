# ep0015 · 搭子 (dā zi)

**의미**: (유행어) 딱 한 가지 활동만 함께하는 사이 (an activity-only buddy) / 글자 그대로: 짝을 맞추다(搭) + 접미사(子) — 동료보다는 가깝고 친구보다는 먼, 그 사이의 거리. `饭搭子`(밥친구)·`旅游搭子`(여행친구)·`健身搭子`(운동친구)처럼 **명사 + 搭子**로 얼마든지 만들어 쓸 수 있습니다.

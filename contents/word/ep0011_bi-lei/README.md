# ep0011 · 避雷 (bì léi)

**의미**: (유행어) "여기 가지 마 / 이거 사지 마"라고 남에게 미리 경고하다 (steer clear) / 글자 그대로: 벼락(雷)을 피하다(避) — 여기서 `雷`는 돈 쓰고 후회하는 것(맛없는 가게·재미없는 드라마·쓸모없는 물건). 당해서 후회하면 `踩雷`, 미리 알려주면 `避雷`. 种草(사고 싶게 만들기)의 반대말.

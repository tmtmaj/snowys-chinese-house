# EP0002 《绿茶》 Script — Style A: 친근한 언니/오빠

### 🎬 Opening 📌 `00_title.png`

大家好！今天我们来学一个很有意思的词——绿茶！
等等，不是你喝的那杯绿茶哦。
绿，就是绿色；茶，就是茶叶。
但是现在，绿茶常常用来形容一种人——表面清纯，其实心机很重。
到底是什么样的人呢？我们一起来看看吧！

> 心机，指心里的算计；心机很重，就是很会算计。
> 表面清纯、其实心机重——这就是绿茶！

# ep0016 · 翻车 (fān chē)

**의미**: (유행어) 자신만만하게 장담한 일이 남들 다 보는 앞에서 사실과 어긋나 무너지기 (crash and burn) / 글자 그대로: 차가 뒤집히다 — 원래는 교통사고를 뜻하지만, 지금은 라이브 커머스·발표·공언이 공개적으로 무너지는 순간을 가리킵니다. 핵심은 **"장담했던 그 지점에서 반박당한다"** 는 것 — 그냥 실패한 건 翻车가 아니고, `说的和做的对不上` 이어야 翻车입니다.

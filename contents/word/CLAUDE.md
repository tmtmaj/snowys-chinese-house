# 小雪的中文屋 — Word Study Cards (`word/`)

## 개요

중국어 단어 학습 카드 생성 시스템. 단어 하나를 입력하면:
- 1920×1080 PNG 카드 세트 (YouTube 롱폼용)
- 중국어 선생님용 촬영 스크립트 (MD + HTML)
- 메타데이터 JSON (카드 시퀀스, repeat 횟수)

메인 파일: `card_generator.py`

---

## 디렉토리 구조

```
word/
  card_generator.py
  ep0001_网红/
    cards/           ← PNG 카드 18장
    index.html       ← GitHub Pages 스크립트 뷰어
    script.md        ← 선생님 낭독 스크립트
    metadata.json    ← 카드 시퀀스 + repeat 횟수
  ep0002_XXX/
    ...
```

에피소드 디렉토리명: `ep{num:04d}_{word}` (예: `ep0001_网红`)

---

## 카드 시퀀스 (에피소드당)

| 번호 | 파일명 | 설명 | repeat |
|------|--------|------|--------|
| 00 | `00_title.png` | 단어 타이틀 카드 | 1 |
| 01 | `01_p1_sep.png` | 第一段 구분 카드 | 1 |
| 02~04 | `0N_p1_s1~s3.png` | 문단1 문장 카드 (3장) | 2 |
| 05 | `05_p1_full.png` | 문단1 전체 카드 | 1 |
| 06~10 | (문단2 동일 구조) | | |
| 11~15 | (문단3 동일 구조) | | |
| 16 | `16_review_sep.png` | 复习 구분 카드 | 1 |
| 17 | `17_review_full.png` | 전체 복습 카드 (중국어만) | 1 |

**규칙: 문장 카드는 2회 반복, 문단 전체/복습은 1회**

---

## 디자인 토큰

```python
W, H    = 1920, 1080
MARGIN  = 140
BG_BASE = (220, 188, 148)  # Warm Sand
DARK    = (42,  26,  10)   # Dark ink (메인 텍스트)
MID     = (98,  68,  38)   # Warm brown (핀인)
LIGHT   = (142, 105,  68)  # Muted brown (영어)
ACCENT  = (190,  80,  30)  # Terracotta (포인트)
```

## 폰트 규칙

| 용도 | 폰트 | 비고 |
|------|------|------|
| 중국어 본문 | SimKai (`simkai.ttf`) | stroke_width로 볼드 시뮬레이션 |
| 핀인 / 영어 | NotoSansSC-VF + NotoSansKR-VF | 가변폰트, bold=True |
| 한국어 | NotoSansKR-VF | is_korean() 감지 후 자동 전환 |

- 중국어 폰트는 `FONT_CN_MAIN`, 핀인/영어용은 `FONT_CN` (NotoSansSC)
- 볼드: `f.set_variation_by_axes([700])` (가변폰트), SimKai는 `stroke_width = max(1, size//60)`

---

## 동적 폰트 사이징

- 문장 카드: `scale = 1.3` 에서 시작해서 내용이 맞을 때까지 0.05씩 감소
- 문단 전체 카드: `scale = 3.0` (3문장 있어서 자동으로 작아짐)
- 복습 카드: `scale = 2.0`
- 최솟값: `scale = 0.3`, 글자 최소 크기 12px

---

## 끊어읽기 표시 (∨)

**기준: PSC 보통화 수준 시험 停顿 규칙**

| 규칙 | 예시 |
|------|------|
| 주어 4음절+ → 술어 앞 | `成为网红的秘诀∨到底是…` |
| 문두 상황어 2음절+ 뒤 | `不过现在∨`, `有一天∨` |
| 연…都 구조 | `连猫和狗∨都能当网红` |
| 복문 접속사 앞 | `…，∨但我已经买了` |
| 연동문/겸어문 → ∨ 없음 | `他去图书馆借了一本书` |

- 쉼표·마침표 등 문장부호가 있는 자리에는 ∨ 중복 불필요
- 데이터에서 `∨`로 표기, 렌더링 시 ACCENT 색 소문자 `v`로 표시

## 왼쪽 액센트 바

- 문장 카드: 중국어 + 핀인 + 영어 3개를 하나로 묶는 세로줄
- 문단 카드: 문장별 각각 바
- `bar_x = MARGIN - 24`, 너비 5px, ACCENT 색

## EPISODES 데이터 구조

```python
{
    "word":     "网红",
    "pinyin":   "wǎng hóng",
    "desc_en":  "internet celebrity",
    "emoji":    "📱",          # 현재 미사용 (이모지 제거됨)
    "script": {
        "opening":      "大家好！...",    # 오프닝 나레이션 (중국어)
        "p1_intro":     "好，我们先来看第一段…",
        "p1_s1_note":   "注意这个句型…",  # 단어 해설
        "p1_wrap":      "好，第一段结束！…",
        # p2_, p3_ 동일 구조
        "closing":      "大家都记住了吗？…",
    },
    "paragraphs": [
        [  # 문단1 (3문장)
            {"cn": "网红∨是什么？", "py": "…", "en": "…"},
            ...
        ],
        ...  # 문단2, 문단3
    ]
}
```

**스크립트는 중국어만 작성** — 중국어 선생님이 직접 낭독, 한국어/영어 설명 없음

---

## 새 에피소드 추가 방법

1. `EPISODES` 리스트에 dict 추가
2. 3문단 × 3문장 = 9문장 작성 (유머러스하고 연결된 스토리)
3. 끊어읽기 `∨` PSC 규칙에 맞게 삽입
4. `script` 필드에 중국어 나레이션 작성
5. `python3 card_generator.py` 실행
6. `ep{num:04d}_{word}/` 폴더 자동 생성

---

## 콘텐츠 기획 원칙

- **대상**: 중국어 완전 초보자
- **문체**: 유머러스하고 이어지는 3문단 스토리 (같은 주인공/상황)
- **난이도**: 비교적 쉬운 어휘, 실생활에서 자주 쓰이는 표현
- **문장 수준**: 문장 하나가 카드 한 장에 자연스럽게 들어올 크기
- **스크립트**: 핵심 어휘 해설 포함, 가볍고 재미있는 톤 유지

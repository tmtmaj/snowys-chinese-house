# ep0013 · 摸鱼 (mō yú)

**의미**: (유행어) 근무 시간에 일하는 척하며 딴짓하기 (slacking off at work) / 글자 그대로: 물고기(鱼)를 더듬어 잡다(摸) — 고사성어 `浑水摸鱼`(혼탁한 물에서 고기를 잡다)에서 왔습니다. 화면엔 엑셀, 폰엔 드라마. 비슷한 말 `划水`, 반대는 `卷`.

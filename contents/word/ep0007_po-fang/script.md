# EP0007 《破防》 Script — Style A: 친근한 언니/오빠

### 🎬 Opening 📌 `00_title.png`

大家好！今天我们来学一个很戳心的词——破防！
破，就是打破的破；防，就是防御的防。
它本来是游戏里的词，意思是攻破了防御。
可现在，破防说的是——心里那道防线一下子被击穿，情绪绷不住了。
我自己就特别容易破防，我们一起来看看吧！

---

### 🖼️ Photo 📌 `00b_collage.png`

大家看看这两张照片——
左边，一个人站在一面裂开的盾牌前，玻璃碎得到处都是。
右边，一个大男孩站在雨里，脸上分不清是雨水还是眼泪。
这就是破防——再硬的防线，也有被击穿的一刻。我们慢慢来看。

# ep0019 · 炒鱿鱼 (chǎo yóu yú)

**의미**: (유행어) 회사에서 잘리다 · 사람을 자르다 (get fired / fire someone) / 글자 그대로: 오징어를 볶다 — **원래는 요리 이름**. 오징어를 볶으면 돌돌 말리는데, 옛날 직원이 잘리면 침구(铺盖)를 돌돌 말아 안고 나가야 했던 데서(卷铺盖走人) → 말리는 **모양**이 같다는 것에서 **炒鱿鱼 = 짐 싸서 나가다 = 해고당하다** 로 전용됐습니다. 광둥어에서 온 표현이지만 현재는 표준어 전역에서 쓰는 대표적 직장 유행어.

> **1단락 구조**: ①원래는 요리 → ②`鱿鱼卷起来的样子` ↔ `铺盖卷起来的形状` (**모양=모양** 비교) → ③`铺盖一卷，人就要走了` → 그래서 `被炒鱿鱼 = 被开除`
> **스토리**: 새엄마가 된 표姐, 3주 연속 지각. 아침에 상사 전화 → 사무실 호출. 문 앞에서 마음속으로 *"이번엔 정말 잘렸구나"*. 문을 열자 상사가 서랍에서 홍바오를 꺼냄. **잘린 게 아니라 연말 보너스 조기 지급**.
> **은유↔실사 사진 짝**: 볶은 오징어 요리(왼쪽=原义) + 사무실 상사가 부하 지목하는 순간(오른쪽=现代义). 사진 카드에서 단어의 의미 이동이 그대로 설명됨.

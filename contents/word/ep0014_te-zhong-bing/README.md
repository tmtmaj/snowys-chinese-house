# ep0014 · 特种兵 (tè zhǒng bīng)

**의미**: (유행어) 최소 비용·최소 시간으로 최대한 많은 곳을 도는 극한 속성 여행 (extreme budget travel) / 글자 그대로: 특수부대 병사 — 원래는 군인을 뜻하지만, 지금은 밤기차에서 자고 이틀에 여덟 군데를 도는 젊은 세대의 여행 방식(`特种兵式旅游`)을 가리킵니다. 반대는 느긋한 `躺平式旅游`.

# ep0017 · 上头 (shàng tóu)

**의미**: (유행어) 빠져서 도저히 못 멈추는 상태 / 순간 이성을 잃고 충동적으로 구는 것 (hooked, can't stop) / 글자 그대로: 머리(头)로 올라오다(上) — 원래는 **술기운이 머리로 확 올라오는 것**을 뜻했습니다. 지금은 술 없이도 上头합니다: `这首歌太上头了`(이 노래 중독성 미쳤다), `一上头就下单了`(욱해서 질러버렸다).

> **1단락이 어원에서 현재 뜻으로 3단계로 넘어갑니다**: ①술 마신 뒤 몸이 上头 → ②술 없이도 上头(한 곡이면 충분) → ③현재의 뜻(못 멈춤 + 말이 안 들림).
> **가능보어 2개**를 한 문장에 짝지어 가르칩니다 — `停不下来` / `听不进去` (上头의 양면).
> **양사 4종**도 한 편에 모았습니다 — 首(노래)·部(드라마)·集(회차)·季(시즌).

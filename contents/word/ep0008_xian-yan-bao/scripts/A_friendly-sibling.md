# EP0008 《显眼包》 Script — Style A: 친근한 언니/오빠

### 🎬 Opening 📌 `00_title.png`

大家好！今天我们来学一个特别可爱的词——显眼包！
显眼，就是特别引人注意；包，是对某种人的可爱叫法。
它俩合在一起，可不是一个真的包哦。
显眼包，说的是那种走到哪、都要成为焦点的人。
你身边肯定也有一个，我们一起来看看吧！
